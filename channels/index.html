Channel lists for CHIRP

Pick what your radio can tune, download a file, and import it into CHIRP. It is a starting list for listening and learning what is on the air in Indiana.

For information only. For listening.
  • The file is a list for listening. CHIRP's import can't mark a channel receive-only, so nothing in the file stops a radio from transmitting. What you transmit on is up to your license and your radio, so tailor the list to what you may use. Every row's comment starts with "RX only" as a reminder, and no repeater offsets or transmit tones are set.
  • This page is a signpost, not the authority. Frequencies, tones, and rules change. Check the sources: RadioReference, RepeaterBook (CHIRP can also query it directly), the FCC pages for GMRS, FRS, and MURS, 47 CFR Part 95, and the ARRL band plan.
  • Analog FM only. CHIRP does not program most digital radios (DMR, for example).

Using it in CHIRP

  1. In CHIRP, download from your radio first (Radio, Download From Radio), so you start from its own settings.
  2. Open the file you downloaded here (File, Open) in a second tab. Select the rows you want, copy them, and paste them into your radio's tab. Or use File, Import.
  3. CHIRP skips frequencies the radio can't tune and tells you which. Fix names or frequencies if you like, then Radio, Upload To Radio.
  4. To transmit on a channel you're licensed for, set its offset and tone (for a repeater) in CHIRP yourself; they are not in this file. Check your radio's menu for a transmit-lock or busy-lock option if you want to be sure it stays listen-only.

Run a net or a repeater?

You decide what's said about it. To add a link, update a listing, or have it removed, open an issue, or open a pull request that edits data/nets.json.
