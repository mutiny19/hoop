New here?

The mesh is small radios that pass short text messages to each other with no cell service or internet. Volunteers run relay boxes on rooftops so messages travel across the state. You can be texting on it this weekend for about $30, with no license.

Report

Tell us what you run, what's happening, and what's broken. Reports feed the counts, the map and the event calendar.

  • Counts are shown by county, never by address
  • Events and outages are reviewed before they appear
  • No addresses or personal details, please
  • New protocols with enough users get their own entry

Reports open as a prefilled GitHub issue, so they're reviewed in the open. You'll need a free GitHub account, or just post it in the Discord and someone will file it.

About this site

HOOP is the Hoosier Off-Grid Open Playbook: plays to consider, not rules, kept open for anyone to improve. It does not represent any network, collective, or organization. It exists to soften the onboarding of newcomers and the landing of advanced users, and then to point them on: the Indiana Mesh Discord is where Indiana people talk, and groups like the Central Indiana Mesh Network and NEIMesh are regional communities with their own sites. None of them run or endorse this site. The site is a signpost, not a document repository: it keeps quick-glance settings and links, and points to the projects and groups that maintain each piece. Where an official source exists (a protocol's docs, a group's own site, an agency's page), that source is the authority and this site defers to it. It is informational only and not affiliated with the FCC, the ARRL, any protocol's developers, any agency, or any repeater owner. The soft waterfall and drifting nodes behind the page are drawn in the browser; they are decoration, not live traffic, and a nod to the background on rflab.io. Code and settings are open on GitHub; corrections are welcome by issue or on Discord.
