How to add a project

  1. Check it fits. An off-grid communications project (mesh, ham, GMRS, LoRa, or anything that helps people talk without the grid), made in Indiana or used here. It has to be a public GitHub repository or a Printables model page.
  2. Open the form. Click Add a project. You'll need a free GitHub account; GitHub asks you to sign in first.
  3. Fill in four things: the link, a category, whether it's made in Indiana or used here, and for Printables only, the model's name. Then click Create.
  4. Wait about a minute. An automatic check replies on your issue. If something needs fixing, it says what; edit the issue (the ··· menu, then Edit) and it checks again.
  5. A maintainer approves it. Once approved, the project shows up here within a few minutes, and the issue closes on its own.

The card shows the project's name and its own GitHub description, never a user name. To improve how a GitHub project reads here, edit the description in the repo's About box; the site picks it up the next week. To fix or remove a listing, open an issue. A project whose page disappears is dropped automatically after two weekly checks.
